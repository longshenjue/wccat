# 每日中英文卡片包

后台「分享制作」默认打开「中英双语 · 多图」。使用「中文 / English」切换预览；每张卡的 PNG 按钮下载当前语言。中文与英文长图仍可在带「旧版」的标签中访问。

完整材料对应每种语言四张卡：一张原始 Top 10 总览，以及同样顺序的三张精选详情。总览保留原榜全部话题（不足十条时展示实际数量）。材料不足时，每种语言输出一张总览和实际可支持的 N 张详情，不补造话题；单个可用话题也可生成一张总览加一张详情。

中英文分别发布：材料完整时，英文帖子使用四张英文卡片和英文配文，中文帖子使用四张中文卡片和中文配文。「下载中英双语 ZIP」只负责把这两套独立发帖素材一起下载。文件使用可跨平台解压的扁平 ASCII 名称：

- `en-01-overview.png`、`en-02-deep-dive.png` 至实际详情数；中文对应 `zh-01-overview.png`、`zh-02-deep-dive.png` 等。
- `en-post.txt`、`en-alt-text.txt`、`en-sources.txt`。
- `zh-post.txt`、`zh-alt-text.txt`、`zh-sources.txt`。

两套详情卡使用相同的精选话题 ID、顺序、已批准图片、隐藏设置与已处理图片资产。英文的标题、配文和 ALT 编辑继续保留；英文单独 TXT 下载仍使用既有内容与文件名契约。

中文是当前英文稿所属的冻结日报的即时视图，不另外翻译、不调用 AI，也不增加数据库字段。中文事件说明优先使用保存的完整中文分析；配文优先使用分析摘要，相关性说明优先使用分析的背景语境。已知的榜单通用占位说明不会代替真实事件事实。可视标题、说明与态度标签不再按固定字数加省略号，优先使用画布空白；内容确实过长时在可读字号下调整排版并增高画布，预览与导出采用实际高度。中文内容需要修改时，修改对应中文日报；英文卡片编辑保留在现有编辑区。图片设置同时作用于两种语言。

中文情绪条使用对应话题的中文分析，沿用源分值并说明其为 AI 相对情绪能量、非民调。缺少中文分析时省略情绪条，不把英文估计回译成来源分析。评论仅展示已保存、来源可核对、与该话题分析标签相符的评论，完整展示保存的原文/译文；中文使用原文，不要求已经有英文翻译。没有可用评论时整个区域收起。无评论基础画布为 1200 × 1500；一条和两条可用评论的基础高度分别为 1900、2200，长文可继续增高。采样时间保留在来源文本中，不占用图片行。

中文视图检查服务端按实际日报内容计算的来源指纹、保存稿指纹、总览 ID 与顺序、精选话题 ID 以及相应中文事实材料。即使话题 ID 没变，日报内容更新也不能与旧英文缓存拼接。编辑冲突时沿用原有冻结日报和本地草稿机制。中文不能与英文稿安全对应时，中文预览和双语 ZIP 给出重载或补齐日报的提示；既有合法英文预览、单张 PNG 与英文 TXT 仍可使用。

## 本地验证

新增 `tests/daily-bilingual-cards.test.ts` 覆盖原榜完整性、精选顺序、稀疏材料、中文原文评论、两种语言评论数量不同、图片资产与隐藏对齐、来源防串用、英文兼容以及 ZIP 文件元数据。渲染检查复用现有 ShareEn、评论和英文导出测试。
