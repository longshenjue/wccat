# 管理员历史查询与热度变化

使用现有管理员配置登录 `/admin`。后台分为五个 Tab：概览、小时报、日报、归档与存储、任务日志。Tab、日期、采样、筛选、分页、选中条目和趋势范围保存在 URL，刷新与浏览器返回可恢复。归档与清理规则见[数据管理说明](admin-data-archives.md)。

## 小时报与原始 item

在“小时报”选择北京时间日期和当天实际存在的采样时段。日期按快照标识所属日期归类，详情另外显示实际保存时间；采集可能跨过小时边界。

- “聚合话题”查看排名、综合热度、来源与已保存分析。
- “原始条目”查看各平台保存的原始字段、互动数据与原文链接。
- 可按标题关键词和来源筛选，默认每页 20 条。
- 点击“查看详情”可复制 JSON、打开原文；唯一关联到聚合话题的原始条目提供关联入口。
- 查询只读，不重新抓取、不调用 AI。空日期不会回退到其他日期。

主库与注册归档统一查询。每个快照先选择生成时间更新的版本，时间相同主库优先；条目和分析来自同一胜出来源。翻页或打开详情时若版本已改变，页面要求重新选择采样，防止混用新旧记录。

## 热度变化

聚合话题详情提供“当天 / 近7天 / 近30天”两张图：综合热度分与榜单排名。综合分不是浏览量或人数；排名图 #1 在顶部。日期范围以当前选择日为结束日，采用北京时间。

点选或用左右方向键选择采样点，查看热度、排名、来源数量及实际保存时间。“查看这次采样”可以跳转至对应条目；也可展开采样数据表。

曲线按同标题记录追踪，同时核对话题 ID、标准化标题与完整标题。标题中的不同符号保留区分；标题变体、碰撞或歧义记录不会强行合并。采样存在但未匹配时不补热度 0；长于4小时的观测间隔用虚线，连线不表示未观测期间的真实热度。

## 日报与提前生成

“日报”中选择日期，查看已保存日报、Top10 条目、分析、中文稿件及英文内容。浏览不会触发翻译。可直接生成或覆盖同日期日报，执行后自动进入任务日志。

允许选择未来日期。选择 D 日，目标窗口固定为 D-1 日 02:00 → D 日 02:00；提前执行时，只使用截至执行开始时已实际采集的数据，标记“提前生成”，保存实际采样范围及次数。没有有效数据时仍禁止生成和覆盖。

例如北京时间11月13日下午选择11月14日，会使用11月13日02:00之后已有的数据。采集跨过02:00才结束的记录，按实际保存时间归入窗口，不会仅因小时标识较早而遗漏。

后台和日报页面都会展示提前生成状态。自动任务仍每天北京时间02:00运行；`npm run daily` 默认仍使用最近一个已结束的02:00窗口。

## 查询成本与数据范围

趋势查询按日期裁剪归档，读取单话题标量，不加载整月快照与原始条目。日报按实际采集时间筛选，可能检查所有含小时记录的注册归档；主库和新归档提供采集时间索引。历史已清理且未恢复时不能凭空恢复走势。

所有接口要求管理员登录。正常历史查询与曲线展示不调用 AI；生成日报会按既有配置调用 AI，并保留对应任务日志。
