# 单话题双语分享与编辑推荐

本功能支持每日一套英文四图主帖，以及从所选日期和前一天挑出的 2–3 条单话题。
每条单话题同时生成英文、中文本地化文案与卡片，不会自动向 X 发布。

## 入口与制作

1. 管理后台 → 小时报 → 查看详情 →「生成单话题分享」。原始条目存在关联聚合话题时，使用该聚合话题的已保存分析。
2. 管理后台 → 日报 → 选择条目 →「生成单话题分享」。
3. 管理后台 → 分享制作 →「今天与昨天，哪些话题值得讲清楚」→ 从 English picks 或中文推荐选择。

打开编辑器只读取资料。先查看原始来源与材料限制，再选择栏目、点击「生成双语文案 · AI」。
任务在后台继续执行，编辑器轮询完成后载入保存稿；也可从任务日志重新打开。
正常生成请求一次 AI；仅数字校验未通过时，最多追加一次较短的定向修正，保留其他文案。
任务日志会列出失败字段和不匹配的数字。修正后仍不满足来源或结构要求时停止，不会覆盖已有稿件，也不会持续重试。

三个栏目分别为：

| 栏目 | 中文名称 | 材料要求与编辑重点 |
|---|---|---|
| Inside China's Internet | 中文互联网观察 | 一个具体事件或文化现象，以及海外读者缺少的语境 |
| In Their Words | 他们怎么说 | 有来源、标签匹配、已有英文译文的真实评论；可以只有一个观点 |
| China Tech, in Context | 中国科技，放回语境 | 科技、汽车或消费发展，区分厂商主张、计划、演示与已确认结果 |

两种语言各有三份不同角度的配文候选、卡片标题、摘要、背景、关注理由、讨论问题、补充回复和 ALT。
英文补足陌生背景，中文从具体情境和实际影响切入；管理员选择理由允许中文。
保存前可独立编辑，语言切换保留两边的修改。未保存稿不能重新生成或导出，版本冲突时保留本地文字。
「重新载入保存稿」会同时核对当前来源；来源已清理时仍可读取冻结稿继续编辑、下载。
ALT 限 1000 个 Unicode 字符。数字、单位、比例、日期与货币角色必须能对应来源；不能自行添加引语或总体民意结论。

## 下载

- 当前语言 PNG：1080 × 1800；有可用评论时为 1080 × 2160。
- 完整双语 ZIP：`en.png`、`zh.png`、`post-en.txt`、`post-zh.txt`、两种语言的补充回复和 ALT、`sources.txt`、`experiment-notes.txt`。
- 配文文件使用所选择、已编辑并保存的候选。原始评论、点赞和链接来自冻结资料，不能通过文案编辑改变。
- 缺评论不显示评论区；不会显示“采样于 …”时间行。导出前检查排版，超出可读安全区会明确停止，不会静默裁掉内容。
- 生成后仍应核对原文与解释，尤其是人名、传闻、玩梗、因果判断及“首次/最大”等比较性主张。自动校验不等于完整事实核查。

## 推荐如何工作

推荐不调用 AI，也不抓取 X。候选来自所选日期及前一天的已保存日报，以及各日最新小时榜的前 60 个聚合话题。
英语、中文分别根据证据完整度、科技实体、跨文化解释、创作者社区、生活关联与核实风险评分。
相同标题、稳定话题 ID 或原始内容链接会去重；不把搜索首页当作同一原帖。
在相近优先级下保留栏目差异；资料不足时可以少于三条。
分值是可检查的编辑排序规则，不是爆款概率，也不是实时 X 趋势。
“某话题正在某平台获得注意力”等本地默认摘要不算故事事实；仅有标题时会降低优先级并提示先补充核实。

六种候选实验来自有限公开案例：具体观察、真实原话、数字语境、证据对照、文化梗解释、事件跟进。
材料不支持某种方式时，使用背景解读或待核实问题。见 [研究与案例](x-editorial-patterns.md)。

## 英文日报四图

ShareEn 首图按原榜顺序展示完整 Top10 英文短标题，以颜色和箭头标出精选条目；后三图逐条展开并显示栏目。
足够支持三条故事时共四图；资料少时减少详情图，不虚构补齐。详情材料不足的条目仍保留在总览榜单中；原日报少于十条时展示实际条数。
正文首句直接进入发现，品牌和来源说明放末尾。已保存的旧版 ShareEn 继续按原布局预览、编辑和导出；
已经生成的编辑版日报也会直接展示完整榜单，重新预览、下载即可，无需再次调用 AI。

## 保存与版本

单话题稿存在主库 `topic_shares`，包含冻结来源和编辑稿，独立于原小时报/日报。
清理小时数据后，仍能通过任务记录中的保存稿 ID 打开和编辑；原始来源被清理后无法再基于该引用生成。
生成请求、排队任务和落盘均核对来源指纹，手工保存还核对稿件 revision；维护前的迟到写入会被拒绝。
本模块不会覆盖原日报，也不会在预览和下载时触发收费请求。

现有按月业务归档未包含 `topic_shares`；已制作素材请另存完整 ZIP，整库备份则会包含此表。
