01

进入项目与启动

先确认当前终端属于 WcCAT 还是 DailyHotApi；两个服务使用不同端口。

8 项

进入本机 WcCAT 项目

只读
cd /Users/longshenjue/Documents/AI-project/wccat

其他 WcCAT 命令均在项目根目录执行。

本机

进入 Northflank WcCAT 容器目录

只读
cd /app

先打开 WcCAT 服务的 Containers → Shell。DailyHotApi 是另一个独立服务。

Northflank

安装锁定版本依赖

依赖安装
npm ci

首次拉取或依赖变更后执行。

本机

开发启动网页

网页
npm run dev

默认 http://localhost:3002；不会同时启动 worker。

本机

构建生产版本

构建
npm run build

生成生产产物，供 start 或 start:cloud 使用。

本机 / 构建环境

启动生产网页

网页
npm run start

需要先构建，端口 3002；仅启动网页。

本机 / 容器

同时启动生产网页与 worker

调用 AI
npm run start:cloud

当前 Northflank 镜像的启动方式。默认包含 worker，WCCAT_WORKER_ENABLED=false 可关闭 worker。网页端口读取 PORT，默认 3002。不要在已运行该服务的 Shell 中重复执行。

本机 / 容器

单独启动定时 worker

调用 AI
npm run worker

立即刷新一次，然后每 4 小时刷新；北京时间每天 02:00 生成前一天日报。Northflank 已启动 worker 时无需再启动。前台运行时 Ctrl+C 停止。

本机 / 容器
02

数据刷新与 AI 分析

刷新会采集新数据；analyze 只处理已保存的最新快照。

5 项

立即刷新热点

调用 AI
npm run refresh

抓取最新热点，生成摘要，并按配置预计算话题分析。AI 调用需要有效的 DeepSeek Key。

本机 / Northflank

刷新并分析 Top 3

调用 AI
npm run refresh -- top=3

把本次话题预分析范围设置为前 3；其他摘要等 AI 调用仍可能发生，并不等于只请求 3 次。

本机 / Northflank

重试最新快照的 Top 3 分析

调用 AI
npm run analyze -- top=3

不重新抓取榜单。已有成功分析会跳过；配置了 DeepSeek Key 时，本地规则回退结果会重试升级。

本机 / Northflank

同步数据（refresh 的同功能入口）

调用 AI
npm run sync -- top=3

当前与 refresh 调用相同的数据刷新逻辑，也可以省略 top 参数。

本机 / Northflank

检查数据源可用性

外部请求
npm run check:sources

逐个检查数据源是否返回数据；不同部署 IP 和站点反爬策略可能使结果不同。

本机 / Northflank
03

日报与英文分享

日报日期是内容所属日，不是生成当天。选择 D 日，对应 D 日 02:00 → D+1 日 02:00。

3 项

生成最近一个完整窗口的日报

调用 AI
npm run daily

生成中文稿件、按需补充 TOP1 分析，并尝试生成英文分享内容。使用最近一个已结束的 02:00 窗口；已有同日期日报会被覆盖。不重新抓取小时数据。

本机 / Northflank

为最新日报补充英文

调用 AI
npm run daily:translate

保留中文内容；已有有效英文时直接复用，不重复翻译。

本机 / Northflank

为指定日期日报补充英文

调用 AI
npm run daily:translate -- 2026-11-15

日期应是已保存日报的 reportDate；2026-11-15 只是示例。此命令补英文，不生成该日中文日报。

本机 / Northflank
04

管理员、归档与存储

导出和清理通过 /admin 操作；注册历史归档后，应用可统一查询主库与归档。

5 项

生成管理员登录配置

生成配置
npm run admin:password

输入至少 12 个字符的密码，输出 WCCAT_ADMIN_PASSWORD_HASH 和 WCCAT_ADMIN_SESSION_SECRET，填入 Northflank Runtime Secrets 或本机 .env.local。需要支持隐藏输入的交互终端。

本机交互终端

启用旧数据库的空间回收能力

存储维护
npm run storage:prepare

用于旧数据库首次启用增量空间回收，保留业务记录。按后台提示使用；不是删除历史数据的命令。

本机 / Northflank

注册一个归档文件

恢复查询
npm run archives:register -- /app/data/imports/wccat-2026-10.sqlite.gz

把示例替换为实际归档文件路径。目标服务使用同版本或兼容版本应用，归档会由应用注册供查询。

目标部署

批量注册多个归档

恢复查询
npm run archives:register -- \
  /app/data/imports/wccat-2026-09.sqlite.gz \
  /app/data/imports/wccat-2026-10.sqlite.gz

多个文件一起传入。同一文件无需重复注册。

目标部署

校验已下载归档

只读
shasum -a 256 /你的下载目录/wccat-*.sqlite.gz

替换为真实下载路径，把计算结果与后台显示的 SHA-256 核对。文件名路径含空格时需要加引号。

时间规则与页面操作

worker：启动时立即刷新一次，之后按以下北京时间运行：

00:0004:0008:0012:0016:0020:00

日报：每天 02:00 生成前一天日报。例如 11 月 16 日 02:00 生成「11 月 15 日日报」，统计 11 月 15 日 02:00 → 11 月 16 日 02:00。

指定日期生成：进入 /admin → 日报，选择内容所属日期。当前 npm run daily 不接收日期参数；不要使用 npm run daily -- YYYY-MM-DD 指定日期。

归档与清理：进入 /admin → 归档与存储，预览、下载、确认清理。当前没有独立 npm 导出或删除命令；小时数据清理保留已生成日报，并保护最近 48 小时及最新小时记录。

分享：进入 /daily，选择中文或 English 后下载 PNG。下载使用已生成内容，不触发新的 AI 分析。

分析数量：不传 top 时读取 WCCAT_ANALYZE_TOPICS，未配置默认 1。成功分析会跳过，本地规则回退可重试；top=3 不是全部 AI 请求次数上限。

模型与配置：DEEPSEEK_API_KEY、DEEPSEEK_MODEL 放在本机 .env.local 或 Northflank Runtime Secrets；默认模型 deepseek-flash。历史日报沿用生成时的编号和统计窗口，查看时以保存内容为准。

刷新入口：公开 /api/refresh 已关闭，使用 CLI 刷新命令。不要用重启代替刷新，重启 worker 还会触发一次立即采集。
