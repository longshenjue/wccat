# 英文日报翻译与校验

中文稿件由 DeepSeek 翻成英文，随后本地检查并保存。公开页面和 PNG 下载只读取缓存，不发起翻译请求。

## 默认策略：优先可用

按用户要求，数值、比例、日期及数量角色的差异只记录提示，不阻止英文保存、读取和下载，也不因此重翻整篇日报。日志级别是 INFO，明确标记“已接受，不重试”，不代表英文生成失败。数字解析器无法归一化某种表达时同样只提示。

仍拦截影响内容完整性和话题对应的错误：无效 JSON、截断响应、缺少或空白译文、未翻译的中文字段、列表缺项、话题或平台身份改变。此类输出最多纠正重试一次。HTTP、认证和网络失败不重试。

历史已保存英文也使用同一宽松规则，避免生成时接受、下载时又被数字校验拦截。只有英文尚未保存时才需要运行补翻译命令：

```bash
npm run daily:translate -- 2026-11-15
```

已有有效英文会复用，不重复调用 AI。中文日报不受补翻译影响。

## 分层实现

- `daily-share-copy.ts`：负责结构、字段完整性和身份校验；数值默认只提示，可传 `numerical: 'strict'` 做诊断和回归测试。生产入口不使用严格模式。
- `translation-numbers.ts`：复用的中英文数字与数量级转换；使用 BigInt 分数表示有限小数和比例，避免浮点误差。按上下文识别中文数词，避免把所有专名、成语中的“一、千、万”等都当作数量。
- `translation-facts.ts`：分别提取比例、日期、季数、标量及可识别的年龄/人数/币种角色；日期范围先归一化，再提取比例，避免把日期中的 “20 in 2026” 当成分数。
- `daily-share-translation.ts`：调用 DeepSeek、输出提示、控制纠正重试。提示包含字段路径和截短的中英文片段，并沿用日志脱敏逻辑。

数值比较独立于 JSON 遍历。后续增加表达式支持时，扩展数字或事实适配器及回归样例，不在日报字段校验里追加标题特例。

真实回归样例：“中国近六成家庭户不超过两个人”与 “Nearly 60% of Chinese households have no more than two people” 数值等价，不应产生提示。`六成 / 60% / sixty percent / 6 out of 10` 归一化到同一个比例；同时覆盖中文数量、英文数词、分数、数量级、全角日期和已有日期区间样例。

这是常见表达的辅助检查，不是通用自然语言事实核验。无法从局部文本可靠关联的专名、指代或省略不会被声称已经验证；默认规则允许译文继续使用，不额外消耗 AI 复核 Token。
