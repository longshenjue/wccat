# 日报所属日期修正

## 需求与实现

- 日报日期为内容所属日 D，统计窗口为北京时间 D 02:00 → D+1 02:00；自动任务在 D+1 02:00 生成 D 日日报。
- 手动选择 D 日解析为次日截止时间，继续允许提前生成，并保护无数据窗口不覆盖日报。
- 自动/CLI 生成仍使用最近一个已结束窗口；后台默认选择该窗口的所属日。
- 采样时间筛选和边界规则未变。历史日报、归档键与正文不批量改写；重新生成的日报采用新日期口径。
