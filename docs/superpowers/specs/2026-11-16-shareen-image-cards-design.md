# ShareEn 图片卡片与可靠生成

用户已确认上一轮建议，要求开始修改；总览固定标题压缩为两行：第一行 `WcCAT Daily Hot · China’s Top 10`（实际不足10条显示实际条数），第二行日期。保留 WcCAT 红蓝字标，不再另起一行品牌或生成抽象标题、摘要。

总览直接呈现原榜英文短标题；焦点仍由海外相关性选择2～3条、保留原排名，配文仍是原榜TOP3。焦点卡使用现有话题封面，管理员可填写受现有图片代理白名单限制的替代图片URL。缺图/加载失败明确提示并允许文字版导出。保留具体标题、What happened及Why it matters，取消独立Context长段落；正文目标合计45～65词。尺寸维持1200×1500，不静默截断。

服务端固定身份、顺序、品牌、日期、配文装饰与alt text。AI主要返回以源topic ID为键的短英文内容和焦点ID。兼容已有数组型AI稿和已存v1缓存。缺少标题优先复用同ID已验证普通英文，能按ID无歧义对应的内容自动归位；缺失/非英文必要字段只补该字段，最多总共两次AI调用。TOP3摘要默认复用原TOP3的英文短标题，避免重复生成失败。未知额外ID隔离，重复身份对应内容视为有歧义，仅补必需字段，不能按位置猜测；采用模型对象之前，扫描原始JSON的重复属性并隔离歧义值。数字差异仅提示。

失败保留旧稿、版本冲突保护、归档只读复制写入和admin认证保持。生成日志区分文案保存与浏览器实际排版/导出状态。本次不自动commit/push，不新做独立预览样稿；运行自动化及实际页面导出验证。
