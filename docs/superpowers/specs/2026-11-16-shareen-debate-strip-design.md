# ShareEn 紧凑情绪对抗条

在已实现但尚未提交的图片卡片改版上继续追加。用户要求无图时可直接隐藏图片区，并恢复 WcCAT 核心的不同网友态度对抗信息，说明不能占据过多空间。

每张海外焦点卡：具体标题 → 可选图片 → 简短事件说明 → 红蓝情绪条 → 一句相关性。无封面、请求失败或管理员选择隐藏时图片区域完全收起，不留大占位框。管理员可切换纯文字布局。

情绪条包含两侧英文短标签（最多3词/30字符）、红蓝归一化能量分值、各一句短说明（最多8词/72字符），字号仍可读。复用该源话题 aiAnalysis.battle 的数值，ShareEn AI只翻译/压缩观点。没有已有分析时，同次AI可提供基于已知材料的编辑估计，标记 AI estimate；不冒充评论人数或民调。无可用态度时不伪造50/50；旧稿可复用原TOP1已有英文，否则后台提示重新生成补齐。

可选 highlight.battle 保存英文短文/分值/来源标记，hideImage:boolean 控制纯文字版。沿用v1缓存与归档，不要求迁移。AI遗漏或态度不可用不能让已经有效的新闻文案全部失败；提供了但不完整的态度仅作可选局部修复，总调用上限仍2次。后台允许编辑态度短文；源分析分值优先，普通下载不调用AI。

保持总览两行固定标题、原榜TOP3配文、海外相关性选题、1200×1500、图片内嵌与严格正文溢出检测。只为紧凑态度摘要作明确的短文本省略，不裁切正文。完成测试、真实页面PNG验证和独立code review；不自动commit/push。
