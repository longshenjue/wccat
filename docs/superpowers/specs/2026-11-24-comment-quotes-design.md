# Sampled comment quotes

The user delegates sampling and presentation decisions. Show actual sampled comments beneath the existing red/blue analysis in hourly topics, daily topics, bilingual long posters and ShareEn. Cats are editorial stance markers, not user avatars. Quote text, source, likes and collection time come from collection, never model-generated quotations. Missing/blocked/closed/unsupported comments hide the section. One-sided evidence stays one-sided.

## Decisions

- Use recognized content URLs only: Bilibili videos (resolve BV to AV if necessary), Zhihu questions/answers, and numeric Weibo post URLs. Search/trending pages do not identify a comment thread and are skipped. No cookie harvesting, browser login bypass or search-based article guessing.
- Default top 10 hourly topics, hard cap 20; at most 2 unique supported threads per topic, one first-page request of 20 root comments per thread, no pagination or nested replies. Bilibili BV resolution costs one additional request. Response cap 512 KiB; request timeout 7 seconds. Global daily network budget 100 (including resolution requests), persistent across restarts, plus existing provider dispatch/lease controls.
- Reuse ProviderState: successful/empty samples cached 4 hours, failed threads cool down 30 minutes (authentication/rate-limit responses 6 hours), network global lease/rate control and generation fencing. Raw bounded samples go to evidence collection records; 7-day provider cache cleanup prevents unbounded per-URL state.
- After existing analysis defines its two attitudes, one bounded AI request classifies at most 40 comments against those exact attitudes and translates them. Only IDs from collected evidence and confidence >=0.8 count. Server chooses each side's highest observed like count, then provider rank. Unknown/neutral/ambiguous comments are omitted. This is highest within the limited sample, never a claim about all comments. Never change the energy bar to match sampled likes.
- Preserve original comment text and provenance; optional English translation is explicitly labeled. Translate the literal, server-selected source excerpt (up to 96 characters), never a model summary; preserve full originals and flag source excerpts in English display/export. Translation failure hides examples from English exports, retaining the Chinese source. No key / classifier failure / insufficient evidence leaves analysis usable. Cache classification by exact samples, metrics and stance labels for 4 hours; failures cool down 30 minutes.
- Selections live in optional TopicAnalysis.commentExamples and therefore travel with JSON snapshots of analyses and daily reports. Existing archives remain readable. Daily generation fills current examples for top 3 using originals in its collected window; shares and downloads reuse stored report evidence and never collect on render/download.
- Shared CommentQuotes component: red/blue cat circles, quote bubbles, source link, observed likes and sampling disclaimer. Sampling times remain in saved provenance and are not displayed in comment cards. Full original text remains in saved data and export sources; ALT contains labeled translated excerpts. Inline deterministic excerpts avoid hiding attribution or shrinking type. ShareEn switches its quote-bearing detail cards to 1900px (one comment) or 2200px (two comments), with measured fitting rather than clipping.
