# 日报分享与刷新入口关闭

用户目标：核实数据源当前可用性；关闭网页公开刷新能力；下载一张中文或英文日报图片，左侧完整 Top10，右侧固定 Top1 的完整分析。

实现选择：使用独立的双栏海报组件和浏览器 PNG 导出，沿用现有深色红蓝视觉。相较直接截图滚动区域，独立海报可以完整展示内容，不受当前选中话题和滚动位置影响。图片固定宽度、自适应高度，文字不截断。

数据与费用：日报生成时补齐 Top1 分析并生成英文分享文案，存入既有日报记录。公开页面只读取结果；下载操作不抓取热点、不调用模型。英文缺失或失败时明确显示不可用，不能把中文标记为英文。

安全与范围：删除 /api/refresh 的公开能力和页面相关提示，CLI refresh/sync/worker 保留。检查数据源及上游，不自动升级整个 DailyHotApi，也不尝试绕过网站访问限制。日报窗口需严格采用最近24小时，避免断档时混入数月前的快照。

验证：拒绝公开刷新请求；24小时边界；英文翻译结构与数值保持；浏览器中英文下载、完整Top10与Top1分析、非Top1选中状态、长文不裁切、图片加载失败回退。
