# ShareEn 配文与焦点卡同步、情绪条补齐

用户已确认配文跟随焦点卡选题，并要求自动日报生成的分享卡同步包含情绪对抗信息。

- 新生成稿编号摘要按 highlights 的话题 ID 与顺序生成，支持2或3条；总览与卡片原始排名保持不变。后台标签说明对应焦点与原榜排名，编辑摘要同步全部候选配文。
- 保留历史 top3 存储键，新增可选 captionBasis=highlights 标识其新语义；无标识的历史稿仍按原榜前三校验与展示，不自动改写历史手工配文，界面说明重新生成可切换新规则。
- ShareEn 初稿必须显式给每个焦点 battle 或 null。缺失/无效的英文态度进入既有最多一次局部修复；已有来源分析时必须尝试翻译并沿用其分值。无来源且明确 null 表示材料不足，不编造比例。
- 情绪条失败不丢弃有效新闻文案，逐焦点日志区分已有分析、AI估计、材料不足、补齐失败。正文与现有候选钩子不因补条而重写。
- 自动日报与手动 ShareEn 使用同一函数，测试贯穿每日保存、焦点选择、渲染与导出；不修改图片版式、小时报或普通中英文长图，不调用真实付费API。
- 本次不自动提交或推送。
