# 管理员分享制作

分享制作集中到 `/admin` → **分享制作**。公开 `/daily` 仅用于阅读日报，不再提供分享图片按钮，也不向公开页面发送 ShareEn 草稿和普通英文分享缓存。

## 后台分工

- 概览：容量与常用操作。
- 小时报：快照、条目、热度与排名曲线。
- 日报：按日期生成/覆盖和查看日报，保持原统计窗口。
- 分享制作：按日期查看分享状态，切换中文长图、英文长图和 ShareEn，生成/重新生成、预览和下载；选择或编辑英文配文。
- 归档与存储：下载归档和清理小时明细。
- 任务日志：日报与分享任务的进度、错误和重试入口。

## 默认生成

`npm run daily`、每天北京时间 02:00 的自动任务及后台手动生成日报，均默认依次生成中文日报、普通英文及 ShareEn。ShareEn 缺失不撤销已保存中文日报；后台显示其状态，可单独重试。没有足够话题或未配置 AI 时明确提示。

ShareEn 保留 WcCAT 红蓝字标，输出一张原始 Top10 总览和 2～3 张海外相关性重点卡。总览顶部依次为三行：WcCAT Logo、`Daily Hot · China Top 10`、日期（不足10条显示实际条数），榜单标签下不再显示额外横线；不再显示抽象总标题或长摘要。焦点卡使用可选话题封面，正文包含具体标题、What happened、紧凑红蓝态度条和 Why it matters。配文以 `WcCAT Daily Hot` 开头，按 `1️⃣ / 2️⃣ / 3️⃣`（两张焦点卡时只有前两条）简述**实际焦点卡对应的话题，并保持卡片顺序**，然后附简短阅读引导。焦点卡可以是原榜 #1、#5、#10，配文也会介绍这三条；总览和卡片继续保留原榜排名。旧缓存仍按原榜前三规则读取，后台会说明；重新生成 ShareEn 后采用新规则，不会自动覆盖手动配文。

## 重新生成与下载

在分享制作选择日期，已有版本可显式重新生成。失败保留上一版可用稿；来源日报已经改变时不会将旧稿套用到新版本。只重新生成分享不会重抓小时榜，也不会重做中文日报。

下载读取缓存：中文和英文为长图 PNG；ShareEn 支持单卡 PNG 和包含有序卡片、英文配文与 alt text 的 ZIP。切换预览、编辑选择和下载本身不调用 AI。

旧日报可补生成：

```bash
npm run daily:shareen -- 2026-11-15
```

显式重新生成已有 ShareEn：

```bash
npm run daily:shareen -- 2026-11-15 --force
```

不传日期时使用最新已保存日报。普通英文补译仍可使用 `npm run daily:translate -- YYYY-MM-DD`。管理员界面可以重新生成普通英文及 ShareEn。

## 数据保存

ShareEn 文案保存在日报 SQLite payload 内，导出日报归档会携带该字段。PNG 和 ZIP 按需在浏览器产生，不在服务器持续累积图片文件。注册归档保持只读；更新其分享内容时会安全复制为主库版本。

所有分享管理接口要求管理员登录，写入要求同源。数值差异继续采用提示策略，不因六成/60%等表达差异禁用英文；结构损坏、空文案、身份错配仍需纠正。

## 图片与局部修复

后台可填写焦点卡的替代配图 URL，留空使用原话题封面，继续受现有图片代理的来源域名白名单限制。缺图、加载失败、无法安全内嵌或勾选“隐藏配图”时，卡片直接收起图片区；预览外提示状态，文字和态度条仍保留。不会用其他话题的图片补位。导出先解码并内嵌图片像素，避免代理 URL 缓存串图和导出阶段重复抓取。ZIP 的 sources.txt 包含焦点卡配图 URL。

新生成稿由程序固定榜单身份、顺序、品牌、日期和配文格式。AI 返回以源 ID 为键的短英文内容和海外焦点选择。乱序会按 ID 归位，漏译优先使用同 ID 的现有英文；焦点配文摘要可直接复用同 ID 的英文短标题。文案必要字段缺失时只补对应字段，文案生成最多调用两次 AI，不重新覆盖已有有效段落。重复或未知身份先隔离；不把未知内容按位置塞进榜单。数字差异仍仅提示。日志中的“文案已保存”不等于保证任何手动修改后的长文本都能导出，图片加载和尺寸会在浏览器实际检查。

旧缓存无需迁移即可使用新版布局；需要更短的焦点正文时，可重新生成 ShareEn。旧 headline/summary/context 作为历史数据保留，但不在新版卡片中展示。

## 紧凑情绪对抗

每张焦点卡支持红蓝能量条、两侧标签和说明。中英文的标题、正文、关注理由、态度标签与说明完整展示已保存内容，不再按固定字数或词数加省略号。优先使用原画布空白，放不下时采用可读的紧凑布局，再按实际内容增高画布；预览与 PNG 使用相同高度。后台可编辑短句，或勾选隐藏配图使用纯文字布局。

自动日报与手动 ShareEn 使用同一生成流程。每个焦点都显式提供态度对象或材料不足标记；漏写态度字段也会进入既有最多一次的局部补齐。已有中文分析时，即使模型返回空态度也会尝试翻译，沿用其红蓝分值，标记 Source analysis（包括规则分析）；无已有分值但材料支持两侧态度时，同一次 ShareEn AI 可提供 AI estimate，不增加长分析任务。没有足够态度材料则略过，不补造50/50。生成日志逐卡记录原榜排名及情绪条就绪、材料不足或补齐失败；后者不会撤销已生成新闻文案。“补齐配图”仅处理照片，需要补情绪文字时使用“重新生成 ShareEn”。旧稿没有英文态度时，可复用身份一致的原TOP1英文分析；其余可重新生成 ShareEn 补齐。

可选态度字段损坏不会禁用整篇新闻或全部下载；管理员编辑时会提示不完整短句。导出的Alt text保留用户图像描述，态度附注按当前编辑稿生成，sources.txt注明分值来源。能量是相对情绪信号，不代表网友人数或民调。

## 焦点配图生成与归档

日报、ShareEn 或全部格式生成时，系统先保存文案，再依次处理最多三张可见焦点图。没有媒体原图时，焦点卡自动收起图片区。原图预览和处理会检查来源以及每次跳转的目标域名，跳过 Pollinations 生成插画。每张图最多调用一次视觉模型，输入为新闻标题和经校验的缩小原图。程序仅在主体保护区域和安全边距都能保留时生成 1072×360 通栏图。其他情况使用 400×480 分栏图完整保留原图。视觉服务暂不可用时也使用此分栏布局。紧凑排版只收去适配留白。

旧稿可在“分享制作”使用**补齐配图**。要重新取景某张已保存的图片，使用该焦点卡下的**重新处理配图**。只生成配图会沿用当前文案。重做同日期日报或重新生成 ShareEn 文字时，再次选中的焦点会保留管理员选择的图片 URL 和隐藏设置，来源、标题、模型和处理规则匹配的配图直接复用。手动更换图片 URL 后保存，会清除旧来源对应的缓存。隐藏配图会保留同来源缓存，方便之后恢复显示。

处理后的 WebP 每张最多 512 KiB，私有字节随 SQLite 日报归档一同导出。注册归档后，已登录管理员可从分享页预览和导出已有配图。管理员接口返回配图元数据，图片单独通过已认证的内容 ID 读取。已有成品的预览和下载只读取缓存。未处理的旧稿仍可使用允许来源的原图预览。


## 发布素材与来源入口

主帖配文、单链接来源回复、固定版本资料页及图片资料编号已接入单话题、小时报选取的话题和日报多图下载。详细操作、下载文件与版本行为见 [X 发布素材与公开资料页](publication-materials.md)。
